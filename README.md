# Linkinbio

Page « link in bio » de Claudio Marcelly : https://marcellyclaudio2623.github.io/Linkinbio/

- `index.html` : la page (HTML, CSS et JS dans un seul fichier), publiée par GitHub Pages depuis `main`.
- `og-image.png` : image d'aperçu quand le lien est partagé.
- `outils/historique-google-sheets.gs` : script Google Apps Script qui enregistre les formulaires et le sondage dans Google Sheets et envoie les contacts dans HubSpot.
